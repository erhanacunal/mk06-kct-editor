    Sequence area

    Sequence syntax: A tap · +LShift press · -LShift release · Ctrl+Alt+T chord · #FE raw byte · k2B key by position number. Sequences send key positions (IBM PC/AT key numbers), written with US key names; the computer’s keyboard layout decides which characters come out. “Add text” converts text using the layout chosen next to it.
